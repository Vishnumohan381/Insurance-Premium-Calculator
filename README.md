
Insurance Premium Calculator

1. Project Overview

The Insurance Premium Calculator is a Python-based
mini project designed to calculate estimated insurance
premiums for Auto and Home insurance.

The application collects customer details, calculates
the base premium, applies an illustrative tax rate,
and generates a quotation summary.

2. Technologies Used

- Python 3.13
- Visual Studio Code

3. Project Features

- Customer information collection
- Auto and Home insurance selection
- Automatic premium calculation
- Tax calculation
- Total premium calculation
- Input validation
- Error handling
- Random policy reference generation
- Insurance quotation display

4. Premium Calculation Rules

Auto Insurance: 2%

Home Insurance: 1%

Illustrative Tax Rate: 18%

Note: These are sample rates used for learning
purposes only.

5. Python Concepts Used

- Variables and Data Types
- Input and Output Functions
- Conditional Statements
- Mathematical Operators
- Type Conversion
- Try and Except
- Random Module
- String Methods

6. How to Run the Project

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open insurance_calculator.py.
4. Run the Python file in the terminal.
5. Enter customer information.
6. Select Auto or Home insurance.
7. Enter the coverage amount.
8. View the estimated insurance quotation.
